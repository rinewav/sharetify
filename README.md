# Sharetify

友だちとプレイリストを共有して、離れていても同じ曲を同じタイミングで聴ける音楽プレイヤーです。

PC ではデスクトップアプリとして、スマートフォンでは PWA として動作します。

[**最新版をダウンロード**](https://github.com/rinewav/sharetify/releases/latest)（macOS / Windows）

## 特徴

- **曲・アルバム・アーティスト・プレイリストの検索と再生**
- **共有プレイリスト** — グループを作って、友だちと一緒に編集できます
- **同時リスニング** — 同じ曲を同じ再生位置で、それぞれの端末から一緒に聴けます
- **スマートフォン対応** — 6 文字の合言葉を入力するだけで、外出先から自分の PC に接続できます
- **オフライン再生** — 端末に保存した曲は、PC が起動していなくても再生できます
- **歌詞表示** — 時刻付きの歌詞が見つかれば、再生に合わせて流れます
- **おすすめ** — 再生履歴をもとに、次に聴くものを提案します
- **履歴の同期** — 再生履歴は自分の PC と端末の間で同期されます（外部には送信されません）
- **last.fm 連携** — 聴いた曲を scrobble できます。API キーは自分の PC にのみ保存されます
- **Discord 連携** — 聴いている曲をプロフィールに表示できます（設定でオン / オフ）

## 仕組み

3 つの部分で構成されています。

```
  スマートフォン (PWA)
        │  音声は自分の PC からだけ受け取る
        ▼
  自分の PC (デスクトップアプリ)
        │  検索・取得・保存をすべて自分の回線で行う
        ▼
  音源の供給元

  ─────────────────────────────────────────

  すべてのクライアント ──▶ 中央サーバー
  （流れるのは識別子・メタデータ・再生位置のみ）
```

- **中央サーバー**が持つのは、アカウント・グループ・プレイリストのメタデータ・再生位置の同期だけです。音声データは一切通りません
- **音声の検索と取得は、各ユーザー自身の PC が、自分の回線で行います**
- スマートフォンと PC の接続は、中央サーバーが引き合わせた後は**端末どうしの直接通信**になります

## 使い方

### PC（ホスト側）

1. [Releases](https://github.com/rinewav/sharetify/releases/latest) からインストーラーをダウンロードして実行します
   - macOS: `Sharetify-x.y.z-universal.dmg`（Intel / Apple Silicon 両対応）
   - Windows: `Sharetify Setup x.y.z.exe`（x64）
2. 初回起動時にセットアップ案内が表示されます。検索エンジンとダウンローダーを自動でインストールします（数分かかります）
   - Python が入っていない場合も、自動でダウンロードして専用ディレクトリに配置します。システムには影響しません
3. セットアップが終わると、6 文字の合言葉が表示されます

署名を行っていないため、初回に警告が出ることがあります。

### スマートフォン

1. [https://sharetify.rine.bio](https://sharetify.rine.bio) を開きます（ホーム画面に追加すると、アプリのように使えます）
2. PC 側に表示されている合言葉を入力するか、QR コードを読み取ります

一度接続すれば、次回からは自動で再接続されます。PC と同じネットワークにいる必要はありません。

> **注意:** PC の電源が入っていない間は、端末に保存済みの曲だけ再生できます。また、ネットワーク環境によっては直接通信を確立できないことがあります（中継サーバーは現在準備中です）。

## プライバシー

- 中央サーバーに音声データは一切送信されません。流れるのは識別子・メタデータ・再生位置のみです
- 再生履歴は自分の PC と自分の端末の間でのみ同期され、外部のサーバーには送信されません
- last.fm の API キーは自分の PC 内（`~/.sharetify/lastfm.json`）にのみ保存されます
- スマートフォンと PC の間の通信は、接続確立後は中央サーバーを経由しません

## 開発

pnpm workspace のモノレポです。

| パッケージ         | 内容                                                             |
| ------------------ | ---------------------------------------------------------------- |
| `packages/shared`  | 共有の型とプロトコル定義                                         |
| `packages/hub`     | 中央サーバー（引き合わせ・アカウント・グループ・同時リスニング） |
| `packages/web`     | PWA（React + Vite + Tailwind CSS）                               |
| `packages/desktop` | デスクトップアプリ（Electron + 内蔵サーバー）                    |

### 必要なもの

- Node.js 22 以上
- pnpm

### 起動

```bash
pnpm install

# 自分の PC の内蔵サーバー（音声の取得を担当。これがないと再生できません）
pnpm --filter @sharetify/desktop dev

# PWA (http://localhost:5273)
pnpm dev:web

# 中央サーバー (http://localhost:47820)。同時リスニングを使うときのみ必要
pnpm dev:hub

# デスクトップアプリごと起動する場合
pnpm --filter @sharetify/desktop dev:electron
```

開発サーバーは内蔵サーバーと中央サーバーを同一オリジンに中継しています（`/node-api`, `/hub-api`）。スマートフォンからは HTTPS でアクセスするため、HTTP のサーバーを直接呼ぶと混在コンテンツとしてブロックされます。この中継は外さないでください。

### ビルド

```bash
# 型検査
pnpm typecheck

# 配布用ビルド
pnpm --filter @sharetify/desktop dist:mac   # macOS universal
pnpm --filter @sharetify/desktop dist:win   # Windows x64
```

## 運営方針

- 無料・非営利で運営します
- 中央サーバーに著作物のデータを通しません
- ローカルファイルなど、特定の供給元に依存しない用途でも動くように作ります

## ロードマップ

- NAT 越えに失敗する環境向けの中継（TURN）
- プレイリストの他サービスとの変換
- 楽曲を練習・制作のリファレンスに使うための機能
